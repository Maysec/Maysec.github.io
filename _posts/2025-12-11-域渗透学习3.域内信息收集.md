# SPN

SPN（ServicePrincipal Names）是服务实例，可以理解为一个服务的唯一标识符，比如HTTP、MySQL。Kerberos身份验证使用SPN将服务实例与服务登录账户相关联。如果在整个林或域中的计算机上安装多个服务实例，则每个实例都必须具有自己的SPN。如果客户端可能使用多个名称进行身份验证，则给定服务实例可以具有多个SPN。SPN始终包含运行服务实例的主体的名称，因此服务实例可以为其主机的每个名称或别名注册SPN。

## SPN格式与配置

SPN的格式严格遵循以下语法结构，不区分大小写：

```tex
ServiceClass/Host:Port/ServiceName
```

组成部分详解：

ServiceClass：服务类型，标识该服务是干什么的

Host：主机名，运行该服务的计算机的FQDN或NetBIOS名

Port（可选）：端口号，如果服务运行在非默认端口，则必须制定

ServiceName：服务名称，用于五分统一主机上的多个服务实例

例：

为SQL Server服务账户注册SPN：

```bat
setspn -S MSSQLsvc/myhost.god.org:1433 owa
```

## 端口扫描

开放了389（LDAP），88（Kerberos），52（DNS）的机器大概率是域控

```powershell
1..254 | % { if (Test-Connection 192.168.1.$_ -Count 1 -Quiet) { try { $s=New-Object Net.Sockets.TcpClient("192.168.1.$_", 389); "IP 192.168.1.$_ is DC"; $s.Close() } catch {} } }
```
